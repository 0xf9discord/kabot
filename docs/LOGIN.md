# 개인 계정 로그인과 봇 실행 (0.3.0)

봇을 실행하는 컴퓨터에는 카카오톡 앱이 필요하지 않습니다. 기존 카카오 계정과 새 기기
등록을 승인할 휴대폰은 필요합니다. 현재 구현은 공개 소스에서 확인한 Android26.8.2
서브 디바이스 프로필을 사용합니다. 자동 토큰 갱신과 QR 로그인은 구현하지 않았습니다.

## 설치

프로젝트 폴더에서:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[loco]'
```

## 첫 로그인

```powershell
.\.venv\Scripts\kabot.exe gui --mode login
```

전용 창에 다음 내용을 직접 입력합니다. Tkinter가 없는 서버에서는 `kabot login`으로
같은 절차를 터미널에서 실행할 수 있습니다.

1. **세션 파일 암호**: 지금 직접 만드는 12자 이상의 암호입니다. 카카오 비밀번호와
   별개이며 로그인 토큰 파일을 암호화하고 다음 실행에서 여는 데 씁니다. 다음 칸에
   같은 암호를 다시 입력합니다. 암호를 잊으면 계정 로그인으로 세션을 다시 만들어야 합니다.
2. 카카오 계정 이메일과 비밀번호를 입력합니다.
3. 기기 등록이 필요하면 시작 여부를 선택하고, 표시된 번호를 휴대폰 카카오톡에서
   승인합니다. 승인 후 창의 다음 안내로 진행합니다.
4. 인증 성공 시 `personal-session.kabot`에 세션을 암호화해 저장합니다. 이어서 채팅
   서버 연결을 확인합니다. 계정 비밀번호와 세션 파일 암호는 파일에 저장하지 않습니다.

프로그램 인수나 채팅에 비밀번호를 적지 마세요. 입력한 암호가 화면에 보이지 않거나
가려져 표시되는 것은 정상입니다.

## 저장된 세션 확인

```powershell
.\.venv\Scripts\kabot.exe gui
```

여기에서는 **세션 파일 암호만** 입력합니다. 카카오 비밀번호 입력이나 기기 등록을
반복하지 않습니다. 터미널에서는 `kabot verify`를 사용합니다. `--session`으로 다른
파일 경로를 지정할 수 있습니다.

`--status-file`을 지정하면 단계, 오류 종류, 서버 상태 코드, 연결 단계와 공개 서버
주소, 인증서 검증 오류를 기록합니다. 계정 이메일/사용자 ID/암호/토큰/인증 번호/기기
UUID/채팅 내용은 기록하지 않습니다.

세션 파일은 scrypt와 AES-256-GCM으로 암호화됩니다. 다른 컴퓨터로 옮길 때도 파일과
별도 암호가 필요합니다. 파일은 사용자 전용 폴더에 보관하세요. 기존 파일은 기본적으로
덮어쓰지 않습니다.

## 채팅방 확인과 봇 실행

먼저 한 번의 실제 답장을 확인하려면:

```powershell
.\.venv\Scripts\kabot.exe gui --mode bot-test
```

세션 암호를 입력하고 로컬 목록에서 테스트할 일반 대화방 번호를 고릅니다. 선택한 방과
답장 내용을 검토한 뒤 `START`를 입력해야 전송 대기가 시작됩니다. 다른 계정에서 그 방에
`/핑`을 보내면 `퐁! Kabot 연결 테스트 성공.`을 **한 번만** 답하고 종료합니다. 자기 계정의
메시지, 다른 방, 일반 대화, 오래된 메시지는 답장 대상으로 삼지 않습니다. 방 이름과
메시지 내용은 진행 파일에 기록하지 않습니다. 서버용 터미널 명령은 `kabot bot-test`입니다.

이미 참여 중인 오픈채팅방에서 텍스트 답장을 시험하려면 다음 옵션을 지정합니다.

```powershell
.\.venv\Scripts\kabot.exe gui --mode bot-test --allow-open --target-room "테스트 방 이름"
```

목록은 `LCHATLIST`의 모든 페이지와 읽기 전용 `CHATINFO`를 사용합니다. 오픈채팅에
별도 제목이 없으면 `INFOLINK`의 방 이름을 조회합니다. 새 방에 자동 참여하지 않습니다.
오픈채팅 프로필 관리, 방 생성·초대·강퇴, 비밀채팅은 이 텍스트 테스트의 범위에 포함하지 않습니다.

지속 실행할 일반 텍스트 봇은 다음 명령을 사용합니다.

```powershell
.\.venv\Scripts\kabot.exe chats
.\.venv\Scripts\kabot.exe init --personal mybot.py
.\.venv\Scripts\kabot.exe personal mybot:bot --chat-id 방ID
```

`chats`는 세션 파일 암호를 입력받아 방 ID를 로컬 터미널에 표시합니다. 실행할 방의
정수 ID를 `방ID` 자리에 넣습니다. 실제 명령에는 한글 자리표시자를 넣지 않습니다.
여러 방은 `--chat-id`를 반복합니다. 선택한 방에 다른 사용자가 `/핑`, `/안녕`, `/방문`
명령을 보내면 텍스트로 답합니다. 자기 계정이 보낸 메시지와 일반 대화는 무시합니다.

개인 계정 어댑터는 텍스트 응답을 지원합니다. 채널 카드나 바로가기 응답을 반환하는
봇 대신 `kabot init --personal`로 만든 봇이나 `examples/text_bot.py`를 시작점으로 사용하세요.

## 세션 만료 후 재로그인

```powershell
.\.venv\Scripts\kabot.exe gui --mode login --replace
```

기존 세션 파일 암호로 열고 같은 기기 UUID를 재사용합니다. 새 계정 로그인이 성공해야
기존 암호화 파일을 교체합니다. 실패하면 이전 파일은 보존됩니다. 자동 비밀번호
재시도나 자동 강제 로그인은 하지 않습니다.

## 연결 오류

IP로 배정된 Android 채팅 서버에는 `kakao.com`을 TLS 서비스 이름으로 지정합니다.
CA 서명과 호스트 이름 검증은 유지합니다. 잘못된 인증서나 다른 이름은 거부합니다.
근거와 테스트는 [TLS 조사](TLS_FINDINGS.md)에 있습니다.

`LocoStatusError`는 실패한 명령과 서버 상태 코드를 보존합니다. 토큰 만료로 거부되면
재로그인을 진행합니다. 메시지를 보낸 뒤 시간 초과가 나면 실제 도착 여부가 불명확해
자동 재전송하지 않습니다. 자동 재접속/영속 중복 처리/이미지 전송은 아직 구현하지 않았습니다.
